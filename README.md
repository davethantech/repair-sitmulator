# BOARD//LAB — PC, Laptop & PCB Engineering Training

This repository contains the BOARD//LAB browser-based training simulator and its development sources.

## Quick start

Open `standalone.html` in a modern desktop browser for offline exercises; or run `node server.js` once the optional local classroom service is installed. The educational models are fictional and must not be used as manufacturing or real-world repair specifications.

See `docs/ENGINEERING_STATUS.md` for validated capabilities, limits, and planned extensions.
