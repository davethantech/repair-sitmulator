Compact MOSFETs use square-law channel models; diodes use an exponential junction model. Reactive parts use backward-Euler numerical integration. No temperature self-heating, junction capacitances, parasitics, device vendor libraries or advanced SPICE compatibility are modeled.

For semiconductor-grade verification, test the same circuit in native ngspice with qualified vendor models and measured reference data. See project engineering status documentation.
Engineering change control

Schematic ↔ footprint audit

The editable schematic is a bounded independent data object. It is compared against physical PCB pad assignments; a mismatch is a real validation error in the training model.

Vendor part number, symbol electrical types, exact pin mapping and actual fabrication geometry require native KiCad ERC/DRC, datasheets and supplier review. Training checks never release a board for manufacture.
